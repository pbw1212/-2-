# 离线复诊登记助手 · D 模块（多轮对话管理与本地登记）

《语音与语言理解综合实践》课程项目 D 模块的完整交付：源码、配置、用例、测试、
实验记录、接口文档、实践报告与演示视频。

D 接收 C 的意图、字段和问答结果，维护多轮登记状态，决定下一轮是补问、澄清、
复述确认还是保存，并把确认后的模拟复诊登记写入树莓派本地 SQLite。

## 快速开始

```bash
cd 02_D源代码
python run.py demo                               # 继承历史 → 改日期 → 确认，写一条登记
python run.py eval --out ../03_D实验记录与结果     # 重跑基线与改进组对照
python -m unittest discover -s tests -v          # 14 项测试
```

环境：Python 3.8+，只用标准库（`sqlite3`、`json` 等），树莓派上把 `python`
换成 `python3` 即可。
