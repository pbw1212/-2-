## 三、如何运行

```bash
cd 02_D源代码
python run.py demo                            # 约 3 秒，打印完整对话并写一条登记
python run.py eval --out ../03_D实验记录与结果    # 重跑基线与改进组对照
python -m unittest discover -s tests -v       # 14 项测试
```

环境：Python 3.8+，无需安装第三方库（`sqlite3`、`json` 均为标准库）。
树莓派上把 `python` 换成 `python3` 即可。
