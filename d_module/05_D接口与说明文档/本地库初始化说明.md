# 本地登记库初始化与查看说明

D 用 SQLite 保存确认后的模拟登记，不依赖数据库服务，单个文件随工程拷贝即可。
树莓派上使用 Python 自带的 `sqlite3`，不需要额外安装。

---

## 1. 初始化

```bash
cd 02_D源代码
python run.py initdb --path registrations.sqlite
```

输出：

```
已初始化本地登记库：.../registrations.sqlite
表：registrations（registration_id 唯一）、dialog_log
```

也可以不单独初始化——第一次运行 `demo`、`chat` 或 `replay` 时会自动建表。

## 2. 表结构

```sql
CREATE TABLE registrations (
    registration_id TEXT PRIMARY KEY,   -- 一次确认一条，唯一约束
    session_id      TEXT NOT NULL,
    profile_id      TEXT,
    department      TEXT NOT NULL,      -- 组内词表 ID，如 rehab
    doctor          TEXT,               -- 可为空，表示未指定
    visit_date      TEXT NOT NULL,      -- YYYY-MM-DD
    period          TEXT NOT NULL,      -- morning / afternoon
    created_at      TEXT NOT NULL,      -- 本地时间
    snapshot_json   TEXT NOT NULL,      -- 复述时的字段快照
    source_json     TEXT                -- 每个字段的来源
);

CREATE TABLE dialog_log (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id  TEXT NOT NULL,
    turn_id     INTEGER NOT NULL,
    phase       TEXT,
    action      TEXT,
    detail      TEXT,                   -- JSON
    created_at  TEXT NOT NULL
);
```

## 3. 查看登记结果

```bash
sqlite3 registrations.sqlite \
  "select registration_id, department, doctor, visit_date, period, created_at from registrations;"
```

或在 Python 里：

```python
import sqlite3
con = sqlite3.connect("registrations.sqlite")
for row in con.execute("select registration_id, department, doctor, visit_date, period "
                       "from registrations order by created_at"):
    print(row)
```

查看某一轮发生了什么：

```bash
sqlite3 registrations.sqlite \
  "select turn_id, phase, action, detail from dialog_log where session_id='c03' order by id;"
```

检查是否出现重复登记：

```bash
sqlite3 registrations.sqlite \
  "select registration_id, count(*) from registrations group by registration_id having count(*) > 1;"
```

正常情况应返回空。

## 4. 一致性约定

| 约定 | 实现 |
| --- | --- |
| 一次确认只写一条 | `registration_id` 主键 + 先查后插 + `IntegrityError` 回滚 |
| 事务成功后才播报 | `save_registration` 里 `commit()` 之后才返回 True |
| 重复确认复用结果 | 已存在时返回 `created=False`，D 播“已经登记过” |
| 写库失败不丢草稿 | 异常时草稿、确认快照都保留，`action=retry_save` |
| 未播完不算确认 | 快照的 `playback_done` 为真才允许写库 |

## 5. 树莓派上的位置与备份

建议放在只读系统盘之外的可写目录，例如 `/home/pi/registration/registrations.sqlite`：

```bash
mkdir -p /home/pi/registration
python3 run.py initdb --path /home/pi/registration/registrations.sqlite
```

离线运行期间每天停机会话后复制一份即可作为备份：

```bash
cp /home/pi/registration/registrations.sqlite \
   /home/pi/registration/backup_$(date +%F).sqlite
```
