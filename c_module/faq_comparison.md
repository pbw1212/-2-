# 复诊 FAQ 的 TF-IDF 与 BM25 对照

对照使用同一份 12 条模拟 FAQ、同一套分词和停用词规则。索引包含每条 FAQ 的标准问和三种变体，共 48 个问法。对每个 FAQ ID 取其问法中的最高分，再按分数排序。答复均取自对应 FAQ 的标准答案。

TF-IDF 用问句词向量的余弦相似度评分。BM25 会压低重复词反复出现带来的额外加分，并按库内问法的词数做长度调整。本次固定使用 `k1=1.2` 和 `b=0.75`，IDF 采用 Lucene 文档所列的公式。[BM25 参数与 IDF](https://lucene.apache.org/core/10_3_1/core/org/apache/lucene/search/similarities/BM25Similarity.html)

## 样本与校准

[问句和标注](data/faq_eval.json)由项目按模拟复诊场景编写。开发集 18 条，含 12 条可回答问句和 6 条库外问句。留出集 32 条，含 24 条可回答问句和 8 条库外问句。留出问句与入库问句、开发集和已有 FAQ 回放在去标点和归一化后无重复。

两种评分尺度不同，因此分别选最低分和前两名分差。校准时先要求保留已有 FAQ 回放的预期结果，再在开发集上选使“答对数加正确拒绝的库外问句数”最高的一组参数。并列时优先选误答更少的配置。留出集用于汇报结果。为只比较检索器，评测直接将问句送入 FAQ 检索。

## 32 条留出问句的结果

| 指标 | TF-IDF 原运行配置 | TF-IDF 校准后 | BM25 校准后 |
| --- | ---: | ---: | ---: |
| 最低分 / 最小分差 | 0.30 / 0.06 | 0.20 / 0.03 | 6.50 / 0.50 |
| 可回答问句的首选命中，筛选前 | 15/24（62.5%） | 15/24（62.5%） | 17/24（70.8%） |
| 实际作答量 | 18/32 | 24/32 | 12/32 |
| 实际答对量 | 10/32 | 14/32 | 9/32 |
| 误答量 | 8/32 | 10/32 | 3/32 |
| 库外拒答或要求澄清 | 3/8 | 3/8 | 7/8 |

首选命中只统计可回答问句，先看排序结果，再应用最低分和分差。实际作答量包括答对和答错。给库外问题返回库内答案也计入误答。没有过阈值或候选相近的回合交给 D 作后续处理。

在本批样例上，BM25 把正确答案排第一的次数多了 2 次。校准后的 BM25 误答更少，同时实际答对也少了 5 条。该配置适合展示少误答和多作答之间的取舍。系统默认仍使用最初的 TF-IDF 配置。

| 留出问句 | TF-IDF 校准后 | BM25 校准后 |
| --- | --- | --- |
| 这次复诊得带上哪些东西？ | 错答为如何取消登记 | 首选排到携带材料，低于阈值而拒答 |
| 怎么预约住院床位？ | 错答为如何预约复诊 | 低于阈值而拒答 |
| 复诊的费用该到哪儿结算？ | 正确答出缴费流程 | 首选匹配正确，低于阈值而拒答 |

本轮证据来自自编文本小样本。真实 ASR 转写、真人问句和树莓派耗时需要后续单独评测。

## 复跑

在仓库根目录运行以下命令。前两条回放 C 的原有功能，后两条输出校准结果和留出集结果。

```powershell
$env:PYTHONUTF8 = '1'
python -B -m c_module
python -B -m c_module --retriever bm25
python -B -m c_module.evaluate_faq
python -B -m c_module.evaluate_faq --details
```
